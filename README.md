# Boutique Stays · 精品住宿

> 我住过日本的房车 Airbnb，布拉格的船屋，还有好几个城市那种藏在巷子里、Google Maps 上都不太好找的小旅馆。
>
> 住酒店和住这些地方完全是两件事。酒店是标准化的舒适，你知道会得到什么。但精品住宿是惊喜，你不知道推开门会看到什么。有一次在京都，整间房就是一辆改装过的露营车，窗外是竹林。那种体验没法用星级衡量。
>
> 后来跟 Airbnb 有了长期合作，写了不少住宿故事。我想把这些经历整理在一起，给那些不想只住连锁酒店的人一个参考。

---

Unique stays and hospitality stories—from an RV Airbnb in Japan to a boat house in Prague, and long-term collaborations with Airbnb.
独特住宿体验与民宿故事——从日本房车Airbnb到布拉格船屋，以及与Airbnb的长期合作。
